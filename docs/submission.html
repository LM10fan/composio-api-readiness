Agent workflow
100 app hints→Tavily search→Groq / OpenRouter free LLM→JSON schema + URL match→resumable checkpoints

Tavily is the search/evidence API; Groq and OpenRouter are the two LLM inference APIs used. The recorded split is 37 Groq rows and 33 OpenRouter rows. The LLM extracted structured fields, and URL matching withheld records unless cited URLs matched retrieved pages. Provider choice was explicit; no paid fallback was enabled. URL matching checks citation provenance only—not claim truth, source authority, recency or whether an integration works.

Human role: inspect official documentation, resolve tier/auth contradictions, correct claims and decide what is safe to present. The risk-focused 10-row check below is not a statistically representative accuracy estimate.

How to reproduce

From the project root, install requirements and supply keys for the selected free provider. The runner checkpoints each app and resumes completed IDs.

pip install -r requirements.txt
python agent/research_free_multi.py --provider groq --workers 1
# or after the free daily limit resets:
python agent/research_free_multi.py --provider openrouter --workers 1

Tavily search uses a separate key and may have plan limits. Free quotas and model availability can change. Keep billing disabled; do not add paid credits for this reproduction.
